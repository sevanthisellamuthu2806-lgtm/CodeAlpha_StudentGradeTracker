# CodeAlpha Student Grade Tracker

## Project Description

Student Grade Tracker is a Java-based console application used to manage student grades and generate a simple summary report.

## Features

- Add student details
- Store student marks using ArrayList
- Calculate average marks
- Find highest marks
- Find lowest marks
- Display student report

## Technologies Used

- Java
- OOP Concepts
- ArrayList
- Scanner

## How to Run

1. Open the `StudentGradeTracker.java` file.
2. Compile and run the Java program.
3. Enter the number of students.
4. Enter each student's name and marks.
5. The program displays the student report, average, highest and lowest marks.
